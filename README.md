# Système de Gestion et de Visualisation de Données

Ce projet est une application web full-stack développée avec **Nuxt.js** pour le frontend et **Django** pour le backend. L'application permet de télécharger des fichiers CSV, d'analyser les données qu'ils contiennent, et de visualiser ces données à travers des graphiques interactifs. L'objectif est d'offrir une interface intuitive et performante pour les utilisateurs.

## Fonctionnalités

- **Téléchargement de fichiers CSV** : Téléchargez et analysez des fichiers CSV.
- **Consultation des données** : Parcourez les lignes et colonnes des fichiers téléchargés.
- **Analyse statistique** : Calculez des indicateurs comme la moyenne, la médiane, l'écart type, etc.
- **Visualisation des données** : Affichez les graphiques interactifs via l'interface utilisateur.
- **API RESTful** : Le backend fournit une API complète pour interagir avec les données.

## Installation

### Prérequis

- **Backend** :
  - Python 3.9 ou supérieur
  - Django 4.0 ou supérieur
  - Django Rest Framework
- **Frontend** :
  - Node.js 18 ou supérieur
  - Nuxt.js 3
  - Tailwind CSS
  - Element Plus
